# Le_SensVisual v0.4.0-rc.23

**A TYY-led visual communication skill for AI agents. By TH_Ng.**

Le_SensVisual helps an agent turn information into a coherent visual experience: a recognisable subject world, meaningful supporting imagery, visible actions and relationships, and calm reading space. It supports images, presentations, teaching material, editorial pages, charts and interfaces without prescribing one output format.

## Start here

For coding agents:

```bash
npx skills add zacqual-sudoGit/Le_SensVisual --skill le-sensvisual
```

Select your supported agent during installation. The Skills CLI requires Node.js 22.20 or later. For other methods, see the [installation guide](https://github.com/zacqual-sudoGit/Le_SensVisual/blob/main/le-sensvisual/INSTALL.md).

## Choose your download

| Download | Intended use |
|---|---|
| **Le_SensVisual-v0.4.0-rc.23.zip** | Complete native skill: SKILL.md, specialist modules, helpers and four visual references. Use this for Claude chat's Skills upload or manual agent installation. |
| **…-chat-guidance.zip** | Complete written guidance and four visual references arranged for chat attachments. Archive reading depends on the host. |
| **…-complete-guidance.txt** | Written guidance for hosts that cannot read ZIPs. Supply the four repository reference images separately. |
| **…-Gemini-stored.zip** | Alternative uncompressed chat archive. It does not guarantee Gemini ingestion; use TXT and images if necessary. |
| **…-github-source.zip** | The source snapshot prepared for this release. |
| **…-offline.zip** | Full distribution with the optional software, upstream sources and construction resources. Larger than the main skill. |

The engine, Chromium extension, Firefox extension, Gardens construction study and upstream source ZIPs are optional resource companions for their respective workflows. You do not need them to use the core visual guidance. The main native and chat packages already include all four visual references.

MANIFEST.json and RELEASE-ASSETS.json describe the packaged release; SHA256SUMS.txt supplies file checksums. GitHub's automatic Source code downloads follow the release tag. The main branch may contain later documentation corrections.

## Included capabilities

- TYY core, eleven review lenses, worked decisions and four visual references.
- Production guidance for direct images and coordinated artwork/assembly workflows.
- Optional PPTX, HTML, asset, extraction and rendering helpers.
- Interface workflows covering design context, components, critique, accessibility, motion, responsive work, hardening and optimisation.
- HTML presentation resources with 12 presets and 34 detailed style systems.

## Changes in rc.23

- Strengthened the Haze worked example to connect source, movement and consequence within the visual world, then connect explanation to people and action.
- Retained the Gardens-first teaching sequence, supporting-world examples, all four reference images and specialist capabilities.
- Adopted the public Le_SensVisual identity and `le-sensvisual` invocation. Recognised legacy installations are backed up by the included installer; existing runtime identifiers remain compatible.
- Completed dependency licence notices and attribution for adapted material.

## Status and compatibility

This is a **public release candidate**, not a claim of universal execution reliability. Source/package reconciliation and local installation checks were completed. No new rc.23 model-output or renderer evaluation was performed, and the npx installation route has not been exercised in this project's evaluation.

Results depend on the model, context access and host tools. Chat attachments and GitHub links do not install missing capabilities. Generated examples demonstrate visual decisions; their historical factual content is not reusable authority.
