# 0.4.0-rc.23

Le_SensVisual (By TH_Ng), formerly VisuaSense, remains a release candidate.

- Replaced one Haze worked-decision row: source, movement and consequence become
  visible together, retaining atmosphere and links to lived actions.
- Preserved Gardens-first teaching, NLB-last teaching, the TYY core, four images,
  all specialist capabilities and the existing choice of output and tools.
- Updated public identity and invocation to `le-sensvisual`. Installer backs up
  recognised legacy Codex/Claude installations; resource import accepts old and
  new roots. Legacy runtime/cache names remain compatible.
- Added dependency MIT notices and explicit Apache adaptation notices.

Native and chat packages include all four images; no optional reference download.
Five existing pinned software/source/construction companions remain available.
The full TXT excludes image pixels and machine-only runtime data.

No new model/output or runtime/renderer test. The Haze change is an informed
teaching refinement, not a measured reliability or comparative-performance gain.
GitHub hosting supplies files; it cannot provide missing host tools or ensure
the model reads them. This source contains no private evaluation chats or audit
folders. Original source revisions and licence notices remain preserved.
