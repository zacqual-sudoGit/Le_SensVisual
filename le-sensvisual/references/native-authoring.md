# Assemble the illustrated composition

Use after assembly is chosen. This recipe supplies HTML/CSS, SVG, drawing-canvas
and document mechanics, including image exports. Carry the resolved TYY composition
through [production](production.md); read the host's actual authoring/rendering
instructions. New PPTX starts with [presentations](presentations.md)'s sequence.
Obtain real artwork before dependent placement. Preserve planned main and
supporting expressions when changing writers or libraries.

## Choose the canvas model

- **Slide/poster:** fix intended aspect and reading distance first. Each page is a complete composition, not an arbitrary montage crop.
- **Editorial/teaching:** use a useful content width and natural flow. Put full programs and secondary references in companions when they displace the explanation; avoid an unnecessarily tall strip.
- **Interface:** adapt to tasks, content and devices. Preserve familiar controls, accessibility and actual states while expressing the world through imagery, type, palette and meaningful relationships.

`scripts/artifact.mjs scaffold editorial|deck|interface <file>` creates an operational shell. Replace its neutral structure with the resolved composition. It supplies mechanics, not the design idea.

## Build the visual carrier and reading field together

Place the planned environmental artwork, people/actions, illustrated objects and local scenes at their intended scales. Compose them with calm reading fields and precise explanatory relationships. Coordinate their detail, material and colour across the complete canvas.

For HTML/SVG assembly, use layered surfaces, actual texture assets, masks and depth to integrate the illustrations; preserve the measured geometry and labelled relationships of diagrams.

Define meaningful HTML variables for text, surfaces, emphasis and status. Use Grid/Flexbox for actual relationships and explicit layered regions where needed. Set `min-width:0` on content that must shrink; wrap long text rather than hiding essential copy. Retain semantic headings and selectable text.

## Make information visible

- **Change:** show the same identifiable object/value before, during and after; preserve quantities/units.
- **Process:** place real stages in reading order, with true endpoints and labelled handoffs. Arrows express movement, dependency or flow.
- **Comparison:** align comparable properties; encode differences with position, scale, labels and colour together.
- **Technical lesson:** connect the situation, input, operation and result. Label depictions with the variables/code they explain. Keep code whitespace intact and provide a copyable file when needed.
- **Claim/decision:** place available evidence or an explicitly illustrative mock-up beside it; distinguish proposals from measured outcomes.

Support body messages with coherent objects/icons, not only a rich header. Change composition when the page job changes while retaining identity.

## Construct actual assets and objects

Track contribution → actual source/path/ID → intended region. Load returned files, fit crop/scale deliberately and use useful alt text for content imagery. Preserve editing operations required by the task; provide copyable code/data when needed. Embed assets deliberately for a single-file delivery where practical. See [assets](assets.md) for extraction/alpha and conditional reconstruction.

When a resolved fixed canvas fits the bundled object vocabulary, the optional
[execution adapter](execution.md) assembles it from the shared record. Richer
responsive/editorial/interface work can use authored HTML/CSS or another host
writer; preserve its meaningful contributions without squeezing them into the
adapter. A scaffold and a resolved production record serve different purposes.

## Render and inspect

Use the host's renderer or `scripts/artifact.mjs render <html> <png>`. Inspect focal and supporting visual contributions at intended reading size. `inspect` reports measurable HTML problems; the engine offers deeper checks. Neither judges TYY benefit automatically.

Check asset loading, hidden/clipped content, hierarchy, contrast, text size and diagram/data consistency. Resolve missing meaning before micro-spacing. Make producer-owned repairs and inspect again. For a changed export, inspect that format too: HTML appearance does not verify PPTX/PDF.

The [Gardens example](../examples/INDEX.md#gardens-layered-slide-composition) documents illustrated assembly. Transfer its coordination and regional meaning, not its particular layout or asset count.
