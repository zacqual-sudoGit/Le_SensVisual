# Resolve the design production will build

Use for substantial creation or redesign. Reuse the brief and the core's
[coordinated task](../SKILL.md#create-as-one-coordinated-task). Store settled
decisions in working context or an existing record; a new DESIGN.md/JSON file
is only a storage choice.

## Separate three jobs

- **Facts and purpose:** audience, use, required content, evidence and brand commitments. For a continuing product this may live in PRODUCT.md.
- **Visual system:** durable type roles, palette meanings, materials, imagery and recurring components. Inspect existing code/assets and DESIGN.md; retain an established identity within the requested scope.
- **Artifact design:** this page's job, selected expressions, composition and construction. Its local arrangement is not a rule for every page.

## Settle decisions production consumes

Reuse the core's map. Settle what the viewer sees in the opening and useful
supporting regions before assigning tools: actual subjects, actions, relationships
and their audience benefits. A section name or container describes organisation;
the [worked decisions](meaning.md) resolve its visual expression. Select production
for this composition and the requested operations, then brief its contributions.

Resolve destination proportions, focal scale and reading fields together.
Specify the shared illustration/material language, type hierarchy and semantic
colours once, with deliberate regional variations. An artwork brief needs its
subjects/actions, viewpoint, final-scale detail and copy/layering needs; a diagram
needs true objects, states, connections and labels; a chart needs real data,
encoding and scale. [Production](production.md) supplies the construction details.

## Choose a direction without ceremony

Continue a settled brief. If a consequential choice remains, offer genuinely
different compositions or references using real user content. Ask only for the
choice that changes the result; ordinary work does not require three previews.
Existing [examples](../examples/INDEX.md) show useful decisions, not model training.

For a set, assign complementary jobs such as orient, explain, compare, demonstrate
or support action. Let those jobs organise each page while preserving the shared
identity. For teaching, give the worked situation room to explain the concept;
precise code/formula/data can occupy a quiet field or copyable companion.

## Continue from the same design

Carry settled decisions through artwork requests and consumed placements. When
a result or tool constraint invalidates a treatment, revise the affected dependency
while retaining its audience benefit and coherent identity. Inspect the actual
artifact against the brief and TYY, including opportunities never selected;
use [review](review.md) for the completion judgment.
