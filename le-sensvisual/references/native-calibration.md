# Calibrate the intended visual experience

Resolve the visual experience before choosing production. Prefer the user's
current reference; otherwise inspect one relevant owner-selected example below.
Open the actual image when vision is available. Descriptions without the image
do not establish visual inspection; disclose unavailable access.

| Reference | Use it to understand |
|---|---|
| [Gardens](../examples/gardens/preview.jpg) | Main deck exemplar: environmental header, anchor scene, illustrated problem objects, local faded scenes and readable audience cards share one world. |
| [LoopLunch / rc.17b](../examples/looplunch.jpg) | Actions, deadlines, a genuine service loop, supporting symbols and a business decision belong to one workplace experience. |
| [Haze](../examples/haze.jpg) | Faded environmental detail reinforces individual explanatory regions; distinct symbols and treatments connect explanation with public action. |
| [NLB proposal](../examples/nlb-proposal.jpg) | Reader activity, illustrative interfaces, human handoff and supporting card imagery make a proposed service experience tangible. |

Identify what appears in both opening and supporting regions, the benefit it
supplies and how it coexists with readable information. Use [meaning](meaning.md)
to resolve those expressions in the current subject. Select useful functions
and appropriate richness; the references do not mandate cards, fading, a palette,
photorealism, a scene count or a tool. Technical work retains truthful mechanisms
and precise labels within the same visual ambition.

The [index](../examples/INDEX.md) gives origins and limits. These images calibrate
visual decisions, not factual source material or guaranteed skill performance.
Only Gardens has the supplied assembly map; LoopLunch documents a complete-image
route. Other routes are unverified. Inspect construction records only when useful
to a chosen method. Judge actual TYY benefits before correctness/geometry polish;
visible factual errors still require correction before real use.
