# Craft (deprecated alias)

`craft` is a deprecated alias for an ordinary request to make new visual work. It adds no setup, interview, checkpoint, tool, or quality behavior. Apply WORKFLOW.md's normal routing and [new-work.md](new-work.md). Reuse a sufficient brief; a missing PRODUCT.md does not block creation. Use [init.md](init.md) when durable product discovery is requested or materially missing, rather than requiring its interview for every task.

Do not tell users they need to invoke `craft`. Natural requests such as “build this feature,” “make a landing page,” or “redesign this screen” use the same flow.
