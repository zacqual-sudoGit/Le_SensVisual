# Le_SensVisual integration policy

This module is part of Le_SensVisual, not a second skill to activate. Resolve its
base directory as this module directory; the parent SKILL.md is the entry point.
User intent and facts, TYY benefits, and the current artifact design govern all
specialist suggestions. Read relevant resources only. Compose the subject's
scenes, illustrated objects, meaningful relationships and information within one
visual identity. Produce the contributing artwork, obtain the returned assets,
and integrate them through the parent's coordinated workflow. Adapt preset
styling to this composition and audience.
The parent core's actual-host check and coordinated tool jobs apply even when
this specialist procedure uses another writer. Choosing a specialist is not
permission to omit selected artwork. Strict plate/raster/fidelity gates apply
only to the deliberately selected accepted-composition engine route. They do not
define fresh production. Ordinary chat
does not acquire engine, filesystem or image access by reading this module.
Render/verify the actual result; technical checks are separate from TYY judgment.
Tools require the stated host capabilities. Publishing, external messaging,
paid API use and host-configuration changes require applicable authorization.
Source notices and hashes identify the imported implementation and adaptations.
