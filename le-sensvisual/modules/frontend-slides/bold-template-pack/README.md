# Optional style catalogue

The 34 systems are style resources under the parent TYY design authority. Use
them for a fitting subject and audience; they do not choose the output format.

Read selection-index.json to shortlist by mood, tone, best_for, avoid_for,
formality, density and scheme. Read relevant preview.md cards, then only the
chosen design.md. Honour a supplied direction or delegated design choice.
Offer previews when a consequential aesthetic choice is unresolved; their
number follows the actual decision, with no compulsory three-option round.

The source recipes document particular examples: their fonts, palette, corners,
imagery, density and coordinates are material to adapt. Build the current
subject's world and useful supporting illustrations. Replace original brand
marks, dummy charts, QR-like decoration and image placeholders with actual
content or remove them when irrelevant. A placeholder does not fulfil artwork.

For HTML decks, use the module's current stage/runtime and print guidance.
Source 1920×1080 coordinates are reference proportions; compose at the requested
dimensions and scale the whole stage uniformly. A reading page uses natural flow.
Use one controller. The alternative deck-stage.js component is included here;
its goTo/index/length API differs from the parent runtime. Preserve required assets by embedding or
bundling them explicitly. Adapt recipes for other requested media through their
supported writers. Inspect the actual result for TYY contribution, readable copy,
loaded artwork, overlap and clipping.
