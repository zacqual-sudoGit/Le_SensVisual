# Frontend Slides resources within Le_SensVisual

This is the integrated specialist module, credited to Frontend Slides and its
contributors under MIT. Follow [WORKFLOW.md](WORKFLOW.md) under the parent TYY
authority. The full original README and repository remain in the pinned source
archive under `third-party/`; the module is already included in this package.

Included capabilities: visual style previews; 12 presets and 34 optional detailed
systems; HTML structure, selected-aspect stage behavior, animation patterns,
existing PPTX extraction, static PDF export and optional Vercel deployment.

The parent package adds a complete deck controller, actual text editing/saving,
cross-platform render/inspect/PDF helpers and richer PPTX ingredient extraction.
Use [the parent presentation guide](../../references/presentations.md) and
[tool guide](../../references/tools.md) for the executable paths and dependencies.
Use only the style resources relevant to the actual subject. Publishing requires
the user's request and configured hosting; local delivery does not.

Install the integrated Le_SensVisual folder using its own installer. Installing a
second stock skill is unnecessary for these included resources and would create
a competing entrypoint. The user's requested output and the parent's illustrated
composition govern production. HTML tools do not claim editable PPTX export.
