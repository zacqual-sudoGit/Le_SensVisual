# Le_SensVisual (By TH_Ng)

**0.4.0-rc.23 — release candidate**

Create visual communication with a recognisable subject world, meaningful
imagery and relationships, calm reading fields and visual harmony. TYY guides
the design; the user's task and output govern delivery. Image, slide, editorial,
teaching, chart and interface work share the core. Editability is conditional.

## One complete skill

Start with [SKILL.md](SKILL.md). The main installation includes all parent
references, specialist instructions, execution helpers, style systems and visual
calibration previews. Load only resources relevant to the current task. Large
software, upstream source and full construction studies are pinned optional
resources, supplied as complete companions. All capabilities remain represented;
their actual execution depends on the host and any stated setup.

| Part | Purpose |
|---|---|
| Core and eleven TYY lenses | World, opportunity recognition, visual meaning, composition, harmony and evidence-based review |
| Production and format recipes | Coordinate artwork, actual asset transfer, assembly and inspection; direct complete-image generation stays direct |
| Python/Node helpers | Optional image-result saving, asset binding, PPTX/HTML construction, extraction, rendering and installation |
| Interface suite | Product/design context, components, critique, accessibility, motion, responsive work, hardening and optimisation |
| HTML slide library | Navigation, optional editing, animation, 12 presets and 34 detailed style systems |
| Optional engine/integrations | Detector, accepted-reference measurement, live variants, hooks and browser extensions; verified external resource cache and explicit setup |
| Examples and provenance | Inspectable references and honest origins; examples are not training or reliability evidence |

Read [INSTALL.md](INSTALL.md) for installation, optional resource acquisition and
chat/repository access. [CAPABILITIES.json](CAPABILITIES.json) maps specialist
resources; [DELIVERY.json](DELIVERY.json) fixes the main installation contents.
CHAT-GUIDE.txt is a reduced core adapter inside the complete package; it is not
a substitute for the specialist library or a claim of permanent installation.
The generated chat-guidance edition includes all specialist instructions/styles
as addressable text sections and four owner-selected previews. It is a guidance
attachment, not an executable installation. The full-depth TXT is a reference
library; read relevant sections rather than preloading every style.

All four same-dimension JPEG calibration previews are included in the native
and chat packages. Original PNGs remain in development records; no separate
reference download is needed.

## Production

Resolve what the viewer sees and understands in the opening and supporting
content, with atmosphere, relationships and calm reading fields. Then choose
tools for that complete design and the required operations. Gardens, LoopLunch,
haze and NLB calibrate different visual functions. Worked decisions carry the
selected functions through generation or assembly; they do not claim matched
output tests. Generation briefs the composition and copy
together; assembly carries actual contributions into the selected writer.
Inspect the delivered result. A planned illustration needs its intended expression.
The optional record/writers assist execution; they cannot call a host-private
image tool or force an LLM to understand/apply the guidance.
