# Release status - 0.4.0-rc.23

Le_SensVisual (By TH_Ng), formerly VisuaSense, is a release candidate.

The approved visual refinement replaces one Haze worked-decision row. It joins
fire sources, smoke movement and an affected city within the atmospheric world,
then connects explanation with people and action. Gardens remains the first
worked reference; NLB remains last. No checklist, format default, new image or
execution gate was added. The core TYY action flow and eleven lenses are intact.

All four same-dimension JPEG references remain in the native and ten-file chat
packages with unchanged image bytes. All specialist guidance, 12 presets, 34
detailed styles and helpers remain. Five existing pinned software/source/full
construction companions preserve all 73 resource members. The full-depth TXT
contains written guidance/source, without image pixels or machine-only data.

Public discovery uses `le-sensvisual`. Codex/Claude installation backs up a
recognised legacy `visuasense` installation outside discovery. Resource import
accepts either archive root. Existing helper filenames, environment variables
and caches retain their compatible names. Added dependency licence notices and
explicit adaptation notices preserve third-party terms; original work is MIT.

This revision receives source, syntax, link, manifest, package-preservation and
local installation reconciliation only. No new model/output or runtime/renderer
test is authorised or claimed. The previous low-effort rc.19/rc.22 recycling
comparison produced strong visual worlds in both arms, without a clear overall
winner; both left a causal illustration opportunity. This refinement is an
informed teaching change, not evidence of a measured performance gain.

Tools, model attention and archive access depend on the host. Gemini ZIP access
is not guaranteed by compression mode. Repository hosting does not install tools
or guarantee that a model loads the guidance. Publication and further output
tests remain subject to owner approval. No public repository has been published.
