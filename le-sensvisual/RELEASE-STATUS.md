# Release status

## v0.4.0-rc.23 · Public release candidate

Le_SensVisual (By TH_Ng) is publicly available on [GitHub](https://github.com/zacqual-sudoGit/Le_SensVisual), with versioned packages on the [rc.23 release page](https://github.com/zacqual-sudoGit/Le_SensVisual/releases/tag/v0.4.0-rc.23).

The release includes the TYY core, eleven review lenses, worked decisions, all four visual references and specialist capabilities. The output format follows the user's brief and available tools. Larger software/source/construction resources are optional companions.

Earlier low-effort rc.19/rc.22 comparisons produced strong visual worlds in both versions without a clear overall winner. The rc.23 teaching refinement is not a measured comparative-performance gain. Reference images are design studies, not reliability benchmarks.

## What depends on the host

- The model must be able to access the relevant guidance and visual references.
- Image generation, asset transfer, authoring, rendering and editing require supported tools.
- ZIP ingestion varies by chat app. Use the complete-guidance TXT and separate reference images if an archive is unreadable.
- Installing or reading the skill does not supply missing services or guarantee instruction adherence.
